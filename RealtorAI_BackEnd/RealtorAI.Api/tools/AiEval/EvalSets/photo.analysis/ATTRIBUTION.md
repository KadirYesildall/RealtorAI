# Attribution: photo.analysis evaluation set `photo-rooms` v1

The photographs listed here are used, unmodified, to evaluate vision models for the
`photo.analysis` task (SC-002). **None of the image files are stored in this repository.**
`rooms-v1.json` records where each file comes from and its SHA-256, and
`aieval --fetch-eval-sets` downloads it from that source into a local cache outside the
repository. The harness sends the model a downscaled, metadata-stripped copy, as it does for
an upload. The product never displays or republishes these photographs.

Each entry gives the title, author, source and license (TASL), as the Creative Commons
Attribution licenses require. Titles and authors are as the source page states them.
CC0 and public-domain photographs need no attribution. They are listed as well so the
whole set's provenance can be checked in one place.

Generated from `rooms-v1.json`. When the manifest changes, regenerate this file from it;
`AiEvalPhotoTests` fails if an item is missing here.
